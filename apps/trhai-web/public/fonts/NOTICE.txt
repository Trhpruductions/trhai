The fonts in this folder
------------------------

TRH AI serves its fonts from this folder, so building it and running it need
no network. The files are the ones Google Fonts serves for each family, copied
unchanged: one file for each group of characters.

All four families are published under the SIL Open Font License, Version 1.1,
which allows them to be used and to be passed on with software. The licence,
with answers to common questions about it, is at https://openfontlicense.org

Below, for each family, are the copyright notice its files carry in their own
naming table and the address they give for their licence.
