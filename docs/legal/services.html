TRH AI does not use any advertising, analytics, crash-reporting or tracking service, and loads no fonts, scripts or images from other companies' servers.

For legal review. The app's window is built on Chromium (through Electron). Confirm by watching the app's network traffic, and switch the feature off or list it here.

These are fetched from GitHub and Hugging Face when you install them in Settings, Engine and models, or by TRH AI itself for the parts it needs to start working. Each file is checked against a fixed size and checksum before it is used. They run on your PC and are not part of the installer.

The install records in the app name a licence for Piper, whisper.cpp and ffmpeg but not yet for llama.cpp, the CUDA runtime or eSpeak NG; the licences above for those three are as their makers publish them and should be added to the records. Distributing a GPL program by having the app download it is a question for a lawyer.

6. TRH AI's own name and pictures

The name TRH AI, its lettering and its screens belong to TRH Development. The background picture and the app's icon were made with an image-generating AI, and the icon still shows the product's earlier name, Ascend AI.

For legal review. The two brand images carry metadata naming OpenAI's image model as their maker. Who owns an AI-generated picture, and whether it can be a trademark, varies by country; the owner should decide whether to keep them, and should replace the icon so that it names TRH AI.
